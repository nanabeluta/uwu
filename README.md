# 生活記事本

這是一個純前端生活記事本，所有資料儲存在瀏覽器本機，不需要網路。

## 使用方式

1. 直接開啟 `public/index.html`，或用簡單本機伺服器開啟
2. 註冊帳號或以管理員登入
3. 開始記錄便利貼、選擇顏色，並可刪除自己的便利貼

## 功能

- 註冊、登入帳號
- 預設管理員帳號：`admin@uwu.local` / `admin123`
- 建立彩色便利貼
- 附加圖片
- 刪除自己的便利貼（管理員可刪除所有便利貼）
- 管理員專區可查看所有使用者
- 所有資料儲存在瀏覽器的 localStorage

## 專案結構

- `public/index.html` - 前端頁面
- `public/app.js` - 前端邏輯，使用 localStorage 儲存資料
- `public/styles.css` - 樣式
- `.gitignore` - 忽略不需要上傳的資料
