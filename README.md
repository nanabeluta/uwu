# uwu 分享網站

這是一個簡單的網頁應用，讓任何人可以分享文字與圖片。

## 使用方式

1. 安裝相依套件
   ```bash
   npm install
   ```
2. 啟動伺服器
   ```bash
   npm start
   ```
3. 開啟瀏覽器
   ```
   http://localhost:3000
   ```

## 功能

- 使用者註冊、登入、登出
- 分享文字與圖片貼文
- 編輯 / 刪除自己的貼文
- 留言功能與留言刪除
- 管理者頁面，可管理使用者與貼文

## 管理者帳號

系統會建立一組預設管理者帳號：

- 信箱：`admin@uwu.local`
- 密碼：`admin123`

請上線後儘快修改或重新建立管理者帳號。

## 專案結構

- `server.js` - 後端伺服器
- `public/` - 前端靜態頁面與樣式
- `uploads/` - 上傳的圖片儲存目錄
- `data/posts.json` - 貼文資料儲存檔案
- `.gitignore` - 忽略不需要上傳的資料
